# 수련회 코스게임 대진표 프로그램

웹 브라우저에서 동작하는 코스게임 대진표 프로그램입니다. PC/모바일 모두 지원하며, 같은 네트워크(또는 배포된 URL)에서 여러 명이 동시에 접속해 **실시간**으로 대진표와 결과를 공유합니다.

URL로 접속하면 **① 수련회 레크레이션(대진표)** 과 **② 미니게임** 두 화면만 먼저 보이고, 원하는 쪽을 선택해 들어갑니다.

## 기능

- **팀 수 설정 (관리자 전용)**: 팀 수 설정과 대진표 생성은 **관리자 모드** 안에서만 가능합니다. `+` / `−` 버튼 또는 직접 입력 (짝수만). 코스게임 수 = 팀 수 ÷ 2.
- **자동 대진표 생성**: 모든 팀이 모든 코스게임을 한 번씩 참여하고, 같은 시간에 한 경기만 하도록 배치합니다. **같은 팀끼리 두 번 이상 만나는 경우를 최소화**하며, 불가피하게 재대결이 생기면 대진표에 ⚠ 로 표시합니다.
- **3가지 모드**
  - **관리자**: 팀 수/대진표 생성, 코스게임 이름 수정, 관리자·스탭 비밀번호 설정, 모든 결과 입력·수정.
  - **스탭**: 담당 코스게임 번호 + 비밀번호로 입장 → 담당 코스 결과를 실시간 입력·수정·저장.
  - **참가자**: 본인 팀 선택 → 전체 대진표, 내 팀의 대진 순서·상대·점수·순위 확인 (결과 입력 불가).
- **실시간 동기화**: 스탭이 특정 타임의 결과를 저장하면 모든 접속자 화면에 즉시 반영되고, 해당 경기는 **대진표·시간표에서 "✓ 완료"** 로 표시됩니다 (SSE).
- **화면**: 전체 대진표(팀×코스), 시간표(타임×코스), 결과, 점수 순위, 팀별 대진 순서.
- **모바일 최적화**: 터치 입력, 큰 버튼, 표 좌우 스크롤.
- **🎮 미니게임 (실시간 놀이)**: 첫 화면의 "미니게임" → **로그인**(이름 + 비밀번호. 처음 쓰는 이름은 자동으로 계정이 생성되고, 다음에 같은 이름·비밀번호로 접속하면 점수가 이어집니다. 로그인 정보는 브라우저에 저장돼 자동 로그인됩니다) → **방 만들기**(게임 선택 + 선택적 비밀번호) 또는 **방 참가**(열린 방 목록에서 인원수·잠금 확인 후 클릭, 또는 코드 입력). 팀과 무관하게 여러 명이 실시간 참여 (WebSocket). 로비 방 목록은 디바운스로 묶어 전송하고, 게임 루프는 시작 시에만 돌아 빈 방은 자동 정리됩니다.
  - **🏆 명예의 전당(랭킹)**: **아레나**와 **경찰과 도둑**의 기록만 랭킹으로 집계합니다(룰렛·사다리·제비뽑기는 제외). **종합 / 아레나 / 경찰과 도둑** 탭으로 나뉘며, 상위 3인은 **포디움(🥇🥈🥉)** 으로 강조됩니다. 점수뿐 아니라 **승률·KDA(처치/사망)·평균 처치·최고 연속 처치·검거 수·유물(금고) 훔친 수** 등 게임에서 모을 수 있는 의미 있는 지표를 판수 기준 평균·총합으로 보여주고, 본인 기록은 표에서 하이라이트됩니다. **방 만들기·방 참가 화면**에도 종합 TOP 5 "명예의 전당" 티저가 떠서 경쟁심을 자극합니다.
  - **🔊 BGM·효과음**: 게임마다 분위기에 맞는 배경음악과 효과음(발사·폭발·피격·아이템·대쉬·찌르기·유물 개봉·승리/패배 등)이 나옵니다. 오디오 파일 없이 Web Audio API로 실시간 합성해 별도 다운로드가 없고, 상단바의 **🔊/🔇** 버튼으로 음소거할 수 있습니다(설정은 브라우저에 저장). 브라우저 정책상 로그인 등 첫 조작 이후부터 소리가 재생됩니다.
  - **룰렛**: 방장이 항목을 편집하고 돌리면 모두가 같은 결과를 실시간으로 봅니다.
  - **사다리타기**: 참가자·결과를 입력해 사다리를 만들고, 이름을 탭하면 경로가 그려집니다.
  - **제비뽑기**: 숨겨진 제비를 한 명씩 뽑아 결과를 공개합니다.
  - **🎮 게임 대기방(아레나·경찰과 도둑)**: 아레나와 경찰과 도둑은 시작 전 **대기방**이 먼저 뜹니다. 각자 **✋ 준비 완료** 를 누르면 **준비한 사람은 왼쪽, 아직 안 한 사람은 오른쪽**에 아이디가 나뉘어 표시되고, **방장이 🚀 Go** 를 누르면 **5초 카운트다운** 후 게임이 시작됩니다. 카운트다운과 함께 **전체화면(게임 플레이 모드)** 으로 전환되며, 상단 **⊟** 버튼으로 기본 화면으로 돌아갈 수 있습니다.
  - **실시간 아레나 — 팀 슈팅**: 2·3파전 팀 배틀. 시작 화면/진행 중 모두 팀 선택 가능(진행 중 난입도 즉시 합류). 각 팀 진영에 **넥서스**가 있고 상대 넥서스를 모두 부수면 승리. **넓고 복잡한 맵**에 벽·장애물과 **밀면 움직이는 상자**가 있으며, **카메라가 내 캐릭터를 따라다녀** 3파전에서도 UI와 겹치지 않습니다. **대쉬(⚡)** 스킬과 랜덤 아이템(회복·강공격·이동속도·즉시부활)이 드롭되고, 스킬 버튼에 **남은 쿨타임**이 실시간 표시됩니다. HUD의 **ℹ️ 아이템** 버튼으로 설명을 볼 수 있고, 탈락하면 10초 뒤 진영에서 부활합니다. 모바일에서는 게임 시작 시 전체화면으로 전환되고 조이스틱·스킬 버튼이 화면 모서리에 배치되어 맵을 가리지 않습니다.
  - **경찰과 도둑 (AI인척)**: 탑뷰. 두 가지 모드:
    - **유물부수기**: **AI 봇 없이 유저끼리만** 진행하는 **넓고 복잡한 미로 맵**(1800×1200). **주변 시야만** 보이며, 맵 곳곳의 **유물(3~8개, 방장 설정)** 을 도둑이 모두 부수면 승. 유물 **부수기 시간**·도둑/술래 **시야 범위**는 방장이 설정합니다(경찰 화면에는 25%·50%·75%·100% 단계만 표시). 캐릭터 **이름**이 맵에 표시됩니다. **술래(경찰)도 도둑과 똑같이 조이스틱으로 미로를 돌아다니는 캐릭터** 이며, **도망자보다 조금 느리지만 🌀 벽 돌파(돌진) 스킬**(쿨타임 표시)로 추격합니다. 도둑에 **몸으로 닿으면 검거**합니다. 잡힌 도둑은 **감옥**에 갇히고, 다른 도둑이 감옥을 터치하면 전원 탈출. 시간 내 전원 검거하면 경찰 승.
    - **AI처럼 행동하기**: 경찰 없이 전원이 봇들 사이에 섞여, **찌르기🗡️**로 적을 제거하고 **방어🛡️**로 막습니다. 정지·앉기·손흔들기로 봇인 척 위장 가능. **개인전** 또는 **팀전(최대 4파전)**으로 마지막까지 살아남은 쪽이 승리(같은 팀은 찌를 수 없고, 본인·아군만 표시됨).

## 실행 방법

```bash
npm install
npm start
```

실행하면 콘솔에 접속 주소가 표시됩니다.

- 본인 PC: `http://localhost:3000`
- 같은 와이파이의 휴대폰/다른 PC: `http://<내PC의_IP>:3000`

포트 변경: `PORT=8080 npm start`

### 🌐 공개 접속 주소 자동 생성 (와이파이 무관)

서버를 켜면 **Cloudflare Quick Tunnel로 공개 URL을 자동 생성**해 콘솔에 표시합니다. 이 주소는 다른 와이파이·휴대폰 데이터에서도 접속됩니다. (콘솔에는 `localhost:3000`과 공개 URL만 표시하며, 단축 URL은 만들지 않습니다.)

- 사전 준비: `cloudflared` 설치 → `winget install --id Cloudflare.cloudflared` (설치 후 서버 재시작)
- 표시 예: `공개 URL : https://xxxx.trycloudflare.com`
- 서버(또는 콘솔 창)를 닫으면 공개 주소도 함께 종료됩니다. 임시·랜덤 주소라 재시작하면 주소가 바뀝니다.
- 자동 생성을 끄려면: `NO_TUNNEL=1 npm start`

- 관리자: `yesohyes33!`
- 코스게임 N번 스탭: `courseNyes` (예: 1번 → `course1yes`, 2번 → `course2yes`)

## 데이터 저장

대진표 상태는 `data.json`, 미니게임 계정·랭킹은 `mg-data.json` 파일에 자동 저장되어 서버를 재시작해도 유지됩니다. 처음부터 다시 시작하려면 해당 파일을 삭제하세요.

## 대진표 알고리즘

- 팀을 두 그룹으로 나눈 뒤 라틴방진 기반 교차 배치로 초기 대진표를 구성합니다.
- 이후 담금질(simulated annealing) + 다중 재시작 지역탐색으로 "재대결 쌍" 수를 최소화합니다.
- 대부분의 팀 수(6·8·10·12·14·16·24·30…)에서 **재대결 0**을 달성합니다.
- 4팀은 구조상 재대결 2쌍이 불가피하며(최소값), 일부 팀 수에서는 소수의 재대결이 남을 수 있고 이 경우 화면에 표시됩니다.
