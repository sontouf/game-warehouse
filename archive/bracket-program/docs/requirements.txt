bracket program은 대진표를 잘 짜는 프로그램임.

예를 들어 12 팀의 대진표를 짜야한다고 가정하자.
총 6개의 코스게임을 모든 팀이 한번씩만 참여해야함

한 코스게임에는 팀 대 팀 대결로 진행됨.
즉 n time에서 6개 코스게임에 12개 팀이 2팀씩 각 코스게임에 배치됨.
그 다음 time 이 되면 참여한 코스게임을 제외한 안해본 코스게임에 배정됨.
즉, 참여했던 코스게임은 이제 참여할 수 없음
이때 6 time동안 최대한 다른 팀들과 계속 대결해야함.

화면에는 n개의 팀을 +, - 로 고를수 있는 버튼이 있어야함. 물론 직접 입력도 가능.
이때 n은 짝수여야 함.
그러면 코스게임은 n/2개가 됨.
nx(n/2)의 표가 만들어지면서 위 요구사항을 만족하는 대진표가 완성되면 됨.
똑같은 팀은 아무리 만나도 2번이상 만나면 안됨.
예를 들어 1time 4번 코스게임에서 팀 A와 팀 C가 만나고 4time 6번 코스게임에서 팀 A와 팀 C가 또 만날수도 있지만
최대한 이런 경우도 없으면 함. 한번 만난 팀은 또 안 만나도록. 2번 만난 팀이 있다면 그것도 따로 표시해줘.

코스게임 이름을 따로 수정할 수 있었으면 함.
또한 해당 코스게임의 결과를 기입할 수 있고 이 결과를 보여주는 창이 있었으면 함.

이때 각 팀별로 순서대로 어떤 팀과 대결하는지 순서를 보여주는 창이 있어야 함.

이 프로그램은 웹 브라우저에서 동작하는 프로그램이어야 함.
url 로 접속가능해야 함.

이 대진표 프로그램은 모바일에서도 동작해야 함.
모바일에서는 터치로 입력가능해야 함.
모바일에서는 화면 크기가 작아서 표가 잘 보이도록 해야 함.

맨 처음 화면은 관리자모드, 스탭 모드, 참가자 모드로 맨처음에 선택해야함.
비밀번호 설정은 오른쪽 하단의 관리자 버튼을 통해 설정할 수 있도록 해줘. 
관리자 접근은 비밀번호 yesohyes33! 임
관리자로 접근하면 관리자 비밀번호랑 코스게임 스탭모드 비밀번호 설정도 할 수 있으면 됨

스탭모드는 비밀번호 입력으로 접근가능
스탭 모드로 접근하면 자신이 어떤 코스게임 담당자인지 번호와 비밀번호로 입력하게 해줘. 
예를 들어 코스게임 1번 담당자는 coursr1yes 가 비밀번호야.
스탭 모드로 하면 대진표에 코스게임 결과를 입력할 수 있고 이 결과를 보여주는 창이 있어야 함.
코스게임 결과는 바뀔수도 있으므로 실시간 수정이 가능하게 해줘. save도 있어야해.

참가자 모드로 하면 전체 대진표 화면이 뜨게 되고, 자신의 팀을 입력하는 창이 나와야함.
참가자 모드로 하면 코스게임 결과 입력은 불가하고, 결과와 전체 대진표와 자신의 팀의 대진순서와 얻은 점수를 볼 수 있게 해줘
